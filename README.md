# Vox2You Alto de Pinheiros

Site da landing page Vox2You Alto de Pinheiros.

## Estrutura

- `index.html`, `styles.css`, `brand.css` e `script.js`: arquivos ativos da landing page.
- `assets/`: imagens usadas diretamente pela página.
- `archive/`: referências, conceitos visuais e assets antigos que não entram no runtime atual.
